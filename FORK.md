# Fork provenance

This repository is an independently maintained fork of
[chrisdone/hell](https://github.com/chrisdone/hell).

- The first feature release uses upstream Hell language/runtime baseline
  `2026-05-29`.
- Its source baseline is upstream commit
  [`4c5c076`](https://github.com/chrisdone/hell/commit/4c5c07677cd78a7fd8103aebbac8a1a9f8ee3bb5)
  from 2026-06-04.
- The Application Image Compilation implementation was introduced by feature
  commit `8074dc7b1a692eddf290b87872257df81dc90e0a`.
- The release tag must point to a later release-preparation commit containing
  the reviewed feature, metadata, documentation, licensing, and release
  changes.

Local history confirms that `4c5c076` is an ancestor of `8074dc7`.

This fork and its releases are not official `chrisdone/hell` releases and do
not imply endorsement by Chris Done or upstream contributors. Upstream
authorship, history, and the original BSD-3-Clause notice are preserved.
